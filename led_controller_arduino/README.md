# led_controller_arduino

[English version](README_EN.md)

Прошивка для Arduino Nano или ESP32, управляющая адресной светодиодной лентой WS2812B. Плата принимает текстовые команды по Serial и переключает режимы подсветки и яркость. С компьютера ею управляет ROS 2-драйвер [`led_driver`](../led_driver/README.md).

Это не ROS-пакет: в каталоге нет `package.xml`, и colcon его пропускает. Скетч — `main/main.ino`.

Спецификация протокола — в [глобальном README](../README.md#протокол-управления-светодиодной-лентой).

## Возможности

- Шесть режимов: радуга, бегущая точка с хвостом, два однотонных режима с поочерёдным зажиганием, оранжевый и выключено.
- Выбор режима по названию или номеру, регистр не важен.
- Регулировка яркости 0–255.
- Ответ на каждую команду полным состоянием платы.
- Работа как с переводом строки, так и без него.
- Неблокирующий цикл: эффекты идут по таймерам на `millis()`, без `delay()`.
- Защита от потери байтов на Arduino Nano: лента не обновляется во время приёма команды.

## Оборудование

| Компонент | Значение |
|-----------|----------|
| Лента | WS2812B, 5 В, порядок цветов GRB |
| Плата | Arduino Nano или ESP32 |
| Пин данных | `6` (`LED_PIN`) |
| Количество светодиодов | `30` (`NUM_LEDS`) |

### Подключение

| Лента | Куда |
|-------|------|
| `DIN` | Пин `LED_PIN` через резистор 300–500 Ом, поставленный ближе к ленте |
| `+5V` | +5 В блока питания |
| `GND` | GND блока питания **и** GND платы: земля обязательно общая |

Рекомендуется конденсатор 470–1000 мкФ между +5V и GND у начала ленты: он гасит бросок тока при включении.

Один светодиод на полном белом потребляет до ~60 мА. Прошивка ограничивает ток ленты значением 500 мА (`setMaxPowerInVoltsAndMilliamps(5, 500)`): при большой яркости FastLED сам её приглушает. Поднимайте лимит, только если блок питания выдерживает больший ток.

**ESP32:** у платы логика 3,3 В, а лента ждёт 5 В. Чаще всего работает и напрямую, но надёжнее поставить преобразователь уровня (например, 74AHCT125). Номер пина данных нужно поменять, например на `13`.

## Настройки

Все настройки — константы в начале `main/main.ino`.

| Константа | По умолчанию | Описание |
|-----------|--------------|----------|
| `LED_PIN` | `6` | Пин данных ленты |
| `NUM_LEDS` | `30` | Количество светодиодов |
| `BRIGHTNESS` | `80` | Яркость после включения, 0–255 |
| `BAUD` | `115200` | Скорость Serial. Должна совпадать с параметром `baud` в `led_driver` |
| `COLOR_AZURE` | `(0, 170, 220)` | Цвет режима `AZURE` |
| `COLOR_GREEN` | `(0, 255, 0)` | Цвет режима `GREEN` |
| `COLOR_ORANGE` | `(255, 80, 0)` | Цвет режима `ORANGE`. «Честный» `(255, 165, 0)` на ленте выглядит жёлтым |
| `COLOR_DOT` | `(0, 255, 0)` | Цвет бегущей точки |
| `RAINBOW_STEP_MS` | `20` | Период шага радуги, мс. Меньше — быстрее |
| `DOT_STEP_MS` | `40` | Период шага точки, мс. Меньше — быстрее |
| `DOT_FADE` | `70` | Затухание хвоста за шаг, 0–255. Меньше — длиннее хвост |
| `WIPE_STEP_MS` | `35` | Пауза между зажиганием соседних светодиодов, мс |
| `QUIET_MS` | `30` | Сколько мс после принятого байта лента не обновляется |
| `LINE_TIMEOUT_MS` | `50` | Через сколько мс тишины команда без перевода строки считается законченной |

## Режимы

| № | Название | Поведение |
|---|----------|-----------|
| 1 | `RAINBOW` | Бегущая радуга. Режим после включения платы |
| 2 | `DOT` | Точка `COLOR_DOT` с затухающим хвостом бежит по кругу: после последнего светодиода возвращается на первый. Если свернуть ленту в кольцо, бег выглядит непрерывным |
| 3 | `AZURE` | Светодиоды по одному загораются цветом `COLOR_AZURE`, затем лента горит статично |
| 4 | `GREEN` | То же, цветом `COLOR_GREEN` |
| 5 | `ORANGE` | Вся лента сразу загорается цветом `COLOR_ORANGE` |
| 6 | `OFF` | Лента гаснет |

## Сборка и прошивка

### Arduino IDE

1. Установите библиотеку **FastLED**: «Инструменты → Управлять библиотеками», поиск `FastLED`.
2. Откройте `main/main.ino`.
3. Выберите плату и порт. Для клонов Nano со старым загрузчиком: «Процессор → ATmega328P (Old Bootloader)».
4. Нажмите «Загрузить».

### arduino-cli

Команды выполняются из каталога `led_controller_arduino`.

```bash
arduino-cli lib install FastLED

# Arduino Nano
arduino-cli compile --fqbn arduino:avr:nano main
arduino-cli upload  --fqbn arduino:avr:nano -p /dev/ttyUSB0 main
# клон со старым загрузчиком: --fqbn arduino:avr:nano:cpu=atmega328old

# ESP32 (нужно ядро esp32:esp32)
arduino-cli compile --fqbn esp32:esp32:esp32 main
arduino-cli upload  --fqbn esp32:esp32:esp32 -p /dev/ttyUSB0 main
```

Перед прошивкой остановите `led_driver`: пока нода держит порт, загрузка не пройдёт.

## Проверка без ROS

Откройте Serial Monitor (115200 бод, любое окончание строки) и отправляйте команды:

```
3              → OK AZURE 80
bright 150     → OK AZURE 150
dot            → OK DOT 150
status         → OK DOT 150
```

## Как устроена прошивка

- `loop()` не блокируется. На каждом проходе он читает Serial (`readSerial()`), затем выполняет шаг текущего эффекта (`updateEffect()`). Каждый эффект сам решает по `millis()`, пора ли делать следующий шаг.
- Лента обновляется (`FastLED.show()`) только когда кадр изменился (флаг `needShow`). Статичные режимы после зажигания вообще не трогают ленту: так меньше шансов потерять байты Serial.
- На Arduino Nano `FastLED.show()` на время вывода выключает прерывания, и байты, пришедшие по UART в этот момент, теряются. Поэтому после любого принятого байта лента не обновляется `QUIET_MS` мс. Хост дополнительно «будит» плату пустой строкой перед командой.
- Смена режима (`setMode()`) гасит ленту, сбрасывает состояние эффекта и сразу отвечает `OK`.
- Смена яркости (`setBrightness()`) выставляет флаг `needShow`. Без этого статичные режимы не перерисовались бы с новой яркостью.

## Как добавить режим

1. Добавьте значение в `enum Mode` и название в `MODE_NAMES` **в той же позиции**. Номер режима — позиция в массиве плюс один. Номера принимаются одной цифрой, так что режимов может быть не больше девяти.
2. Добавьте ветку в `switch` в `updateEffect()`. Если режим статичный, задайте цвет в `setMode()`, как у `ORANGE`.
3. Добавьте название в кортеж `MODES` в `led_driver/led_driver.py` в той же позиции и обновите таблицы режимов в документации.
