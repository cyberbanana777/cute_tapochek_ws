# cute_tapochek_gui

[English version](README_EN.md)

rqt-плагин **Motion Studio** для подсистемы движений робота cute_tapochek. Позволяет записать движение с leader-руки, посмотреть его на follower, сохранить в библиотеку и проигрывать сохранённые движения.

GUI ничего не хранит сам: каждая кнопка вызывает сервис или action ноды `motion_server` из [`cute_tapochek_motion`](../cute_tapochek_motion/README.md). Поэтому всё, что делается в GUI, можно сделать и из терминала.

## Запуск

Сначала поднимите руки и `motion_server`:

```bash
ros2 launch soarm101_teleoperate teleoperate.launch.py
ros2 launch cute_tapochek_motion motion_server.launch.py
```

Затем откройте Motion Studio одним из способов:

```bash
# отдельным окном
ros2 run cute_tapochek_gui motion_studio

# внутри rqt: Plugins → Cute Tapochek → Motion Studio
rqt
```

После первой сборки rqt нужно один раз пересканировать плагины, иначе Motion Studio не появится в меню:

```bash
rqt --force-discover
```

## Интерфейс

**Строка связи.** Показывает, на связи ли `motion_server`. Сервер считается недоступным, если статус от него не приходил больше 1,5 с. В этом случае кнопки, требующие сервера, неактивны.

**Библиотека движений.** Таблица с именем, длительностью и описанием каждого движения.

- **Скорость ×** — множитель скорости проигрывания, 0,1–2,0.
- **▶ Играть** — проиграть выбранное движение. То же делает двойной щелчок по строке.
- **■ Стоп** — остановить проигрывание, рука останавливается на месте.
- **Удалить** — удалить выбранное движение после подтверждения.
- **Обновить** — перечитать библиотеку.

**Запись с leader.** Показывает состояние записи: ожидание начала движения, идёт запись (с таймером), проигрывание, несохранённый черновик.

- **ждать начала движения** — если отмечено, запись начнётся, когда сдвинется leader.
- **● Записать** — начать запись. Если есть несохранённый черновик, GUI попросит подтверждения: новая запись его заменит.
- **■ Остановить** — закончить запись, она становится черновиком.
- **▶ Посмотреть** — проиграть черновик на follower.
- **✕ Выбросить** — выбросить запись или черновик.
- **Имя**, **Описание**, **Сохранить** — сохранить черновик в библиотеку. Имя проверяется ещё в GUI: латиница, цифры, `_` и `-`, до 64 символов. Если движение с таким именем уже есть, GUI предложит перезаписать его.

**Телеуправление.** Показывает состояние ретрансляции leader → follower. Кнопки **Включить** и **Пауза** включают её и ставят на паузу. При проигрывании сервер сам ставит телеуправление на паузу. Обратно его включают кнопкой **Включить**: follower плавно догоняет leader и дальше идёт за ним.

**Прогресс и журнал.** Полоса прогресса проигрывания и журнал ответов сервера.

## Типичный сценарий записи

1. Отметьте «ждать начала движения» и нажмите **● Записать**.
2. Выполните движение leader-рукой и нажмите **■ Остановить**.
3. Нажмите **▶ Посмотреть**: follower проиграет черновик, телеуправление встанет на паузу.
4. Понравилось — введите имя и описание и нажмите **Сохранить**. Нет — **✕ Выбросить** или запишите заново.
5. Нажмите **Включить** в блоке «Телеуправление», чтобы снова управлять с leader.

## Сохраняемые настройки

rqt запоминает между запусками множитель скорости и флажок «ждать начала движения».

## Полезные проверки

```bash
# Видит ли rqt плагин
rqt --list-plugins | grep -i motion

# Доступен ли сервер
ros2 topic hz /motion_server/status
ros2 service list | grep -E "motion|recording|teleop"
```

## Зависимости

- ROS 2:
  - `rclpy`
  - `rqt_gui`, `rqt_gui_py`
  - `python_qt_binding`
  - `cute_tapochek_interfaces`
  - `std_srvs`
- Работающая нода `motion_server` из `cute_tapochek_motion`.
